# Candy Crush Soda router references

Put full-screen PNG screenshots in this directory using these names:

- `stage.png`
- `board.png`
- `clear.png`
- `popup.png`
- `tutorial.png`

Multiple examples are supported with names such as `stage_01.png`, `stage_02.png`,
or in subdirectories such as `stage/example.png`. Images are compared after being
downscaled to the size configured in `configs/profiles/candy_crush_soda.yaml`.
